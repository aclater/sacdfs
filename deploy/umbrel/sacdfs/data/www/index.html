sacdfs

Your SACD disc images, as DSF and WAV files, shared read-only.

SMB (Windows, macOS, Linux, players)

Address: smb://HOST:10445/sacd

User name and password: the ones Umbrel shows for this app.

NFS (Linux)

sudo mount -t nfs4 -o port=12049,ro HOST:/sacd /mnt/sacd

Your images

Choose the folder that holds your SACD images (ISO files) in this app's settings, under SACD images. sacdfs only reads it.

Setup and every option: user guide.
